Pulse-Width Modulation (PWM) DC Motor Speed Controller

High-efficiency solid-state motor speed driver with MOSFET switching and analog control input.

01 // Project Summary

Direct current (DC) motors require flexible speed regulation without wasteful energy dissipation through traditional series rheostats. In this project, I designed and implemented a high-efficiency solid-state DC motor speed controller using Pulse-Width Modulation (PWM). By pulsing the supply voltage at a high frequency, the controller regulates the average voltage delivered to the motor armature, enabling smooth speed control, high torque retention at lower RPMs, and minimal thermal loss across the power switching stage.

02 // System Architecture & Circuit Schematics

The control system consists of three main building blocks: an analog control interface (potentiometer / MCU PWM signal generator), an isolated gate-driver stage with an N-Channel Power MOSFET, and an inductive kickback protection circuit for the motor load.

03 // Math, Reasoning & Software Implementation

Pulse-Width Modulation operates by switching the power rail ON and OFF at a high fixed frequency \(f_s\). By varying the ratio of ON time (\(t_{\text{on}}\)) to the total signal period (\(T\)), we precisely regulate the average voltage \(V_{\text{avg}}\) applied across the motor terminals:

\[ \text{Duty Cycle } (D) = \frac{t_{\text{on}}}{t_{\text{on}} + t_{\text{off}}} \times 100\% = \frac{t_{\text{on}}}{T} \times 100\% \] \[ V_{\text{avg}} = D \times V_{\text{in}} \]

Where \(V_{\text{in}} = 12\text{V}\). At \(D = 75\%\), \(V_{\text{avg}} = 0.75 \times 12\text{V} = 9.0\text{V}\).

Because the mechanical time constant of the motor (\(\tau_m\)) is significantly larger than the PWM period (\(T\)), the motor acts as a low-pass filter, converting voltage pulses into smooth rotational velocity and stable torque.

C++ Arduino Software Implementation:

/*
 * PWM DC Motor Speed Controller
 * Author: Victor Iyanuoluwa Akanbi
 * Description: Regulates motor speed via ADC potentiometer input using custom Timer1 PWM frequency.
 */

const int POT_PIN = A0;      // Potentiometer input
const int MOTOR_PWM_PIN = 9; // Timer1 PWM output pin (OC1A)

int potRawValue = 0;
int pwmDutyCycle = 0;
float calculatedVoltage = 0.0;

void setup() {
  // Initialize Serial Monitor for telemetry
  Serial.begin(9600);
  
  pinMode(MOTOR_PWM_PIN, OUTPUT);
  pinMode(POT_PIN, INPUT);

  // Configure Timer1 for 20kHz PWM frequency to eliminate audible motor whine
  // Prescaler = 1, Fast PWM Mode (ICR1 as TOP)
  TCCR1A = _BV(COM1A1) | _BV(WGM11);
  TCCR1B = _BV(WGM13) | _BV(WGM12) | _BV(CS10);
  ICR1 = 799; // TOP value for 20 kHz (16MHz / (1 * 20000) - 1)
}

void loop() {
  // Read 10-bit Analog Input (0 - 1023)
  potRawValue = analogRead(POT_PIN);

  // Map 0-1023 ADC reading to Timer1 TOP range (0 - 799)
  pwmDutyCycle = map(potRawValue, 0, 1023, 0, 799);
  pwmDutyCycle = constrain(pwmDutyCycle, 0, 799);

  // Write duty cycle register directly
  OCR1A = pwmDutyCycle;

  // Telemetry calculation
  float dutyPercentage = ((float)pwmDutyCycle / 799.0) * 100.0;
  calculatedVoltage = (dutyPercentage / 100.0) * 12.0;

  // Print telemetry every 250ms
  static unsigned long lastLogTime = 0;
  if (millis() - lastLogTime > 250) {
    Serial.print("ADC Raw: "); Serial.print(potRawValue);
    Serial.print(" | Duty Cycle: "); Serial.print(dutyPercentage, 1); Serial.print("%");
    Serial.print(" | V_avg: "); Serial.print(calculatedVoltage, 2); Serial.println(" V");
    lastLogTime = millis();
  }
}

04 // Failures, Challenges & Solutions

  • Acoustic Motor Whine (Default 490 Hz PWM):
    Issue: Standard Arduino analogWrite() operates at ~490 Hz, creating an annoying high-pitched metallic buzz in the motor windings.
    Solution: Reconfigured ATmega328P Timer1 hardware registers to increase the PWM switching frequency to 20 kHz—above the threshold of human hearing—yielding silent, silky-smooth motor rotation.
  • MOSFET Thermal Dissipation & Slow Switching Transitions:
    Issue: During initial tests with a 10 k\(\Omega\) gate resistor, the MOSFET spent too much time in the linear active region during turn-ON/turn-OFF transitions, causing excessive heat buildup.
    Solution: Reduced gate resistor to 220 \(\Omega\) and added a 10 k\(\Omega\) pull-down resistor, ensuring rapid charge/discharge of gate capacitance (\(C_{iss}\)) and keeping the MOSFET strictly in saturation/cutoff regions.
  • Inductive Voltage Spikes (Back-EMF Damage):
    Issue: When switching the motor OFF, the collapsing magnetic field created sharp negative voltage spikes exceeding \(-40\text{V}\), threatening to rupture the MOSFET drain-source junction.
    Solution: Installed a high-speed 1N5819 Schottky flyback diode directly across the motor terminals to safely recirculate inductive decay currents.

05 // Real-World Applications

  • Electric Mobility & EVs: Pulse-width modulation forms the fundamental basis for traction motor inverters in electric cars, e-bikes, and electric scooters.
  • Industrial Conveyors & Robotics: Enables precise variable speed control for assembly lines, robotic arm joints, and automated guided vehicles (AGVs).
  • HVAC & Energy Management: Regulates fan and pump speeds dynamically according to thermal load demand, reducing electrical energy consumption by up to 40% compared to fixed-speed systems.

06 // What I Would Have Done With More Budget

  • Full H-Bridge IC (e.g., VNH5019 / L298N): Upgrade from single-direction low-side switching to a full dual H-bridge topology to allow bidirectional motor rotation (FORWARD / REVERSE) and regenerative braking.
  • Quadrature Encoder Closed-Loop PID Control: Integrate an optical shaft encoder with interrupt-driven PID velocity control on the microcontroller to maintain constant target RPM under fluctuating mechanical loads.
  • Isolated Optocoupler Driver (PC817): Add optical isolation between the sensitive MCU microelectronics and high-power 12V motor ground to prevent ground-loop noise and catastrophic high-voltage feedback.
  • Custom Printed Circuit Board (PCB): Design a compact 2-layer PCB in KiCAD with heavy copper traces (\(2\text{ oz}\)) and an integrated aluminum heatsink for high-current industrial operation.
