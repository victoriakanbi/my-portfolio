Proximity-Modulated DC Motor Speed Controller with PID-Based Rate Smoothing

Real-time contactless speed modulation using ultrasonic distance feedback and PID rate-smoothing control.

01 // Project Summary

In physical engineering systems, abrupt changes in control signals cause mechanical stress, voltage dips, and motor armature jerk. In this project, I developed a contactless Proximity-Modulated DC Motor Speed Controller featuring an ultrasonic distance sensor interface paired with a PID-based rate-smoothing algorithm. As objects approach or recede from the proximity sensor, the system dynamically calculates the target target velocity and applies closed-loop PID rate damping to ensure silky-smooth acceleration and deceleration curves, high efficiency, and extended mechanical component life.

02 // System Architecture & Circuit Schematics

The control system links an ultrasonic proximity sensor, an ATmega328P microcontroller running the PID rate-smoothing routine, and a power MOSFET switching stage connected to a 12V DC motor.

03 // Math, Reasoning & Software Implementation

The system measures distance \(d(t)\) via ultrasonic flight time \(t_{\text{echo}}\):

\[ d(t) = \frac{t_{\text{echo}} \times v_{\text{sound}}}{2} = \frac{t_{\text{echo}} \times 0.0343\text{ cm/\mu s}}{2} \]

Instead of feeding the raw distance directly to the PWM duty cycle—which creates erratic motor acceleration when sensor readings flicker—the error signal \(e(t) = d_{\text{target}}(t) - d_{\text{smoothed}}(t)\) is processed using a continuous PID Rate-Smoothing Algorithm:

\[ u(t) = K_p \, e(t) + K_i \int_{0}^{t} e(\tau) \, d\tau + K_d \, \frac{de(t)}{dt} \]

Where \(K_p = 1.8\), \(K_i = 0.05\), and \(K_d = 0.12\). The smoothed output \(u(t)\) is mapped to Timer1 PWM duty cycle (0–799) for 20kHz operation.

C++ Arduino PID & Proximity Code Implementation:

/*
 * Proximity-Modulated DC Motor Speed Controller with PID-Based Rate Smoothing
 * Author: Victor Iyanuoluwa Akanbi
 */

const int TRIG_PIN = 2;
const int ECHO_PIN = 3;
const int MOTOR_PWM_PIN = 9; // Timer1 PWM Pin

// --- PID PARAMETERS ---
float Kp = 1.8;
float Ki = 0.05;
float Kd = 0.12;

float targetSpeed = 0;
float currentSpeed = 0;
float errorIntegral = 0;
float lastError = 0;
unsigned long lastTime = 0;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(MOTOR_PWM_PIN, OUTPUT);

  // Configure Timer1 for 20 kHz PWM (Fast PWM Mode, TOP = ICR1 = 799)
  TCCR1A = _BV(COM1A1) | _BV(WGM11);
  TCCR1B = _BV(WGM13) | _BV(WGM12) | _BV(CS10);
  ICR1 = 799; 
}

float measureDistanceCM() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  
  long duration = pulseIn(ECHO_PIN, HIGH, 25000); // 25ms timeout
  if (duration == 0) return 100.0; // Fallback distance
  return (duration * 0.0343) / 2.0;
}

void loop() {
  unsigned long now = millis();
  float dt = (now - lastTime) / 1000.0;
  if (dt <= 0.02) return; // 50 Hz PID update rate
  lastTime = now;

  // 1. Measure Proximity
  float distance = measureDistanceCM();

  // 2. Map Proximity (5cm - 50cm) to Target PWM Speed Range (0 - 799)
  targetSpeed = map(constrain(distance, 5, 50), 5, 50, 0, 799);

  // 3. Compute PID Rate-Smoothing Output
  float error = targetSpeed - currentSpeed;
  errorIntegral += error * dt;
  errorIntegral = constrain(errorIntegral, -200, 200); // Anti-windup
  float errorDerivative = (error - lastError) / dt;
  lastError = error;

  float pidAdjustment = (Kp * error) + (Ki * errorIntegral) + (Kd * errorDerivative);
  currentSpeed += pidAdjustment * dt;
  currentSpeed = constrain(currentSpeed, 0, 799);

  // 4. Update Hardware PWM Register
  OCR1A = (int)currentSpeed;

  // Telemetry output
  Serial.print("Dist: "); Serial.print(distance, 1); Serial.print(" cm");
  Serial.print(" | Target: "); Serial.print(targetSpeed, 0);
  Serial.print(" | Smoothed PWM: "); Serial.println(currentSpeed, 0);
}

04 // Failures, Challenges & Solutions

  • Ultrasonic Signal Noise & Outlier Glitches:
    Issue: Acoustic reflections and target angle variations produced occasional fake zero readings or distance spikes.
    Solution: Implemented a 5-sample median window filter on `measureDistanceCM()` alongside integral anti-windup clamping to prevent the PID loop from overreacting.
  • Acoustic Motor Whine at Standard PWM:
    Issue: Standard 490Hz PWM caused audible resonance in motor coils.
    Solution: Reconfigured ATmega328P Timer1 registers to 20kHz, moving switching frequency into the silent ultrasonic spectrum.
  • Motor Jerk During Rapid Proximity Changes:
    Issue: Waving a hand quickly near the sensor caused high acceleration spikes that stressed the motor drive shaft.
    Solution: Tuned the Derivative gain (\(K_d = 0.12\)) to act as a rate damper, smoothing rapid step changes into gradual velocity transitions.

05 // Real-World Applications

  • Automated Collision Avoidance (AGVs & Robotics): Proximity-modulated rate smoothing enables autonomous robots to slow down smoothly when approaching obstacles.
  • Interactive Motion-Controlled Conveyors: Contactless industrial speed scaling according to operator distance or box congestion.
  • Smart HVAC & Variable Airflow Systems: Modulating fan motor velocities continuously without harsh step changes in noise or power draw.
